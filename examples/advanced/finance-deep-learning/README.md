# Prerequisit

Install the dependencies and start a Jupyter Lab instance. We recommend doing this in a fresh virtual environment.

```
python -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt
```

Start Jupyter Lab
```
jupyter lab .
```
